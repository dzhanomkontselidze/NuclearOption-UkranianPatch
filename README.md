Мод Української локалізації для Nuclear Option. Працює як плагін BepInEx і перекладає інтерфейс, енциклопедію, підказки та спливаючі описи — усього 1 605 записів.

Вимоги
Nuclear Option (Steam, Early Access 0.32.5+)

BepInEx 5.x

Встановлення
Встановіть BepInEx 5.x у папку гри.

Приклад: C:\Program Files (x86)\Steam\steamapps\common\Nuclear Option\

Запустіть гру один раз і закрийте її. (Це створить структуру папок BepInEx)

Скопіюйте всі файли з цього репозиторію до:
[Папка гри]\BepInEx\plugins\LocalizationPatch\

Якщо папки «LocalizationPatch» немає, створіть її вручну.

Запустіть гру — український переклад застосується автоматично.
